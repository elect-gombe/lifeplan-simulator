# v1（app/）と v2（v2/）の機能差分

最終更新: 2026-09-21。v1 のコード棚卸し（`app/src`、約 14.5k 行）と v2 の実装を突き合わせた結果。

## 1. v2 で新規・強化

### 入力
- プランのリンクを「トラック単位」から「セクション単位（家族/収入/生活費/住まい/子ども/運用/イベント/万一/前提）」に整理。比較ビューが設定差分を自動抽出。
- 詳細ウィザード: 全 9 セクションを下書きで順にたどり、フッターのプレビュー（退職時純資産と差分・枯渇年齢・スコア・今年の貯蓄）を見ながら「このプランに適用」。初回はかんたん 4 ステップ → 「続けて詳しく入力」。
- 住まいを賃貸/購入の「フェーズ」で入力。次フェーズ開始時に持ち家を自動売却（残債・譲渡税・売却費用）。v1 の `housingTimeline` と住み替えイベントの二重構造を統合。
- 子どもの「まとめて編集」モーダル（学年ごとの公立/私立・学費上書き・下宿・大学院・育休・プリセット一括適用・費用プレビュー）。
- 収入/支出イベントに「雑所得として課税」「本人死亡で停止」「インフレ連動」「N 年ごと」を統一付与。
- 住宅ローン控除の認定種別（一般・長期優良・ZEH・省エネ・中古）が計算に効く。v1 は型のみで一律 35 万×13 年。
- 取り崩し順序（特定→NISA / NISA→特定 / 残高比例）と、計画的な取り崩し（定率・定額、開始年齢、開始後の再投資停止）。v1 は順序が型のみで未実装、計画的取り崩しは無し。
- モンテカルロ用の年率標準偏差、ストレステスト（年齢・下落率・回復年数）。

### 計算
- 2025 年度税制改正を反映（基礎控除 58 万/95 万、給与所得控除の最低 65 万）。v1 は基礎控除 48 万固定。
- モンテカルロ（対数正規リターン、10〜90% 帯、枯渇確率）とストレステスト。v1 に確率評価は無い。
- 必要保障額は各死亡年齢で再シミュレーションし、遺族の流動資産最低値から導出。v1 は支出−収入のヒューリスティック。
- パート収入の壁を実装（社会保険の 106 万・130 万、住民税の非課税限度額、国保均等割の軽減）。v1 は給与があれば常に厚生年金・健保を計上し、住民税も均等割が必ず発生していた。
- インフレを生活費・教育費にも適用。v1 はイベント費用・管理費・固定資産税・車維持費にのみ適用され、生活費には掛かっていなかった。
- 特定口座の売却時課税を、不足補填・計画的取り崩しの両方で一貫して計上。

### 出力・UI
- 年表（収入の各列が収入合計に一致する恒等式、収支・残高の連鎖、生涯合計行、CSV）。
- 年別の内訳と収支表（2 タブ）、比較ビューの KPI 表。
- ピン留めグラフ 49 指標（限界税率・負担率・防衛月数・NISA 含み益・取り崩し率など）。localStorage に保存し比較プランを重ね描き。v1 はセッション限りで保存されなかった。
- 明示的な Undo/Redo（v1 はブラウザの戻る/進むで代替）、ダークモード、FP 提案書スタイルの印刷レポート（13 種のページ）、モバイル専用レイアウト。いずれも v1 に無い。
- 生命保険料控除の 3 区分、地震保険料控除、死亡退職金・弔慰金、公的年金の内訳表示。v1 は一般生命保険料のみ。
- 資産推移・収支・税/社会保険チャートから年クリックで内訳連動。
- アクセシビリティ: 全 125 入力にヘルプ、ポータル吹き出し（端で切れない・タッチで開く）、タップ領域 24px 角以上、ライト/ダーク両方で文字コントラスト 4.5:1（大きい文字 3:1）を全ビュー・全モーダルで担保。v1 にヘルプはほぼ無かった。
- チャート配色は色覚シミュレーションで検証（隣接系列の OKLab ΔE）。印刷レポートは A4 の印刷幅に全ページ収まることを実測で確認。v1 は印刷レイアウト自体が無い。
- 入力の反映を軽量化（計算キャッシュ、リンク解決の同一性維持、チャートの描画遅延と 1 パス化）。

## 2. 同等に継承

- 年収・生活費・DC 掛金の階段状スケジュール、配偶者の同等入力、ふるさと納税、退職一時金。
- 住宅ローン: 元利/元金均等、変動金利、繰上返済（短縮/軽減）、借換、ペアローン、団信、売却と譲渡所得税。
- 車（価格・ローン・維持費・買い替え）、保険（定期/収入保障）、死亡イベント。
- NISA 夫婦 2 口座、年間枠・生涯枠、簿価管理と枠復活、口座別利回り、生活防衛資金の下限/上限。
- 老後生活費、子の独立による生活費減額、遺族の生活費割合。
- 所得税累進・住民税、社会保険料控除、配偶者控除/特別控除、扶養控除、生命保険料控除、公的年金等控除、給与＋年金の総合課税、住宅ローン控除の所得税→住民税按分、ふるさと納税上限。
- 老齢基礎・厚生、繰上げ/繰下げ、在職老齢年金、マクロ経済スライド、遺族基礎・厚生と 65 歳以降の併給調整、中高齢寡婦加算の逓減（令和 7 年改正）。
- 相続税（基礎控除・みなし相続非課税・法定相続分課税・配偶者税額軽減）。
- DC/iDeCo の一時金・年金・併用、退職所得控除の通算。
- 教育費テーブル、児童手当、高校就学支援金、多子世帯の大学無償化、育休給付金と年金記録保護、復職後の時短。
- LLM 相談用テキストレポート（前提サマリー・毎年の表・5 年ごとの計算根拠・総括・設定 JSON・分析指示プロンプト）。分析プロンプトは v1 から移植。
- URL 共有（gzip+base64url）、JSON 入出力、旧 JSON のベストエフォート変換。

## 3. 簡略化・削除

### 入力
- 職歴（厚生/国民/共済の期間・平均年収・退職一時金） → 働き方の区分と就職年齢。年金額は年収スケジュールから推定。
- 国民健康保険料率の詳細（平等割・均等割・所得割・限度額） → 概算。
- 贈与イベント（暦年/相続時精算課税の贈与税） → 一時支出として取り込み、贈与税は計算しない。
- 私的年金イベント → 掛金の支出と受取の収入に分解。公的年金等控除の適用可否は指定不可。
- 暴落イベントの年別利回りオーバーライド、年齢別利回りスケジュール → ストレステストに置換。
- イベントの「配偶者死亡時の扱い（継続/停止/減額%）」 → 本人死亡時の停止のみ。
- 目標貯金アンカー（年齢×金額）、結婚支援金・住宅取得援助、扶養控除の持ち主指定、必要保障額の予備資金、本人万一後の配偶者収入の別指定（死亡退職金・弔慰金は 2026-09-20 に追加）。

### 計算
- 会社員 65 歳以上の介護保険第 1 号、75 歳以上の後期高齢者医療保険料は未計上（v1 は概算あり）。
- 配偶者の第 3 号被保険者期間の結婚年齢からの推定 → 無収入・無年金なら被扶養者とみなす簡略化。
- 国民年金は全期間納付とみなす。
- DC の「節税スコア」「厚生年金減少額」の表示。

### 出力・UI
- ガント型イベントタイムライン（住居フェーズバー、ローン・車の仮想サブバー、親子折りたたみ） → 資産推移チャート上部のマーカー。
- 税詳細モーダル（全項目×全シナリオ列、行ホバーのミニグラフ） → 年別内訳の「税・社会保険の計算根拠」パネル（`features/dashboard/TaxDetail.tsx`）。各行にその年の実数を入れた計算式、節税効果（控除なしで再計算した差額）、累進税率の階段図を表示。全シナリオ横並びとホバーのミニグラフは無い（比較はピン留め指標で）。
- 収支の円グラフ、税負担率の専用チャート → 税・社会保険の積み上げチャートとピン留め指標。
- 列幅スプリッター、シナリオ横並び表示、セクション開閉状態の保存。

## 4. 補足

- v2 は `v2/` 配下に未コミット。`app/` は無変更で、CI は旧アプリのまま。
- v1 で型だけあって計算に使われていなかったもの: 取り崩し順序（v2 で実装）、認定種別（v2 で実装）、NISA 口座別利回り・配偶者の生活費 KF（持ち込まず）。
- 復活要望が出やすいと見ているもの: 職歴ベースの年金推定、後期高齢者医療保険料（税詳細の計算式ヒントは 2026-09-20 に復活）。
